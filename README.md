# Cookies Data Analysis Project

## Project Overview
This project focuses on analyzing cookie sales data using Python, Pandas, and Microsoft Excel to extract meaningful insights and support data-driven decisions.

## Tools & Technologies
- Python
- Pandas
- Microsoft Excel
- Jupyter Notebook

## Project Steps
1. Data exploration and understanding.
2. Data cleaning and preprocessing using Pandas.
3. Data analysis to identify sales trends and patterns.
4. Creating an interactive dashboard using Excel.
5. Presenting insights through data visualization.

## Project Files
- `main.ipynb`: Python analysis and data processing.
- `final project dashboard assignment.xlsx`: Excel dashboard and analysis.
